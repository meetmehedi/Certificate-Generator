# Certificate Generator - DIU CPC

A lightweight, web-based certificate generator for the **DIU Computer Programming Club (DIU CPC)** Workshop on *"Research Journey: From Problem Identification to Publication"*.

## Features
- 🎓 **Dynamic Certificate Generation:** Real-time preview of the certificate as you type.
- 🖨️ **Print-Ready:** Perfectly optimized for A4 Landscape printing with exact background color rendering.
- 🔒 **Fixed Details:** Locks in specific workshop dates and details to maintain consistency.
- 📱 **Responsive:** Automatically scales down to fit your browser window while maintaining the exact aspect ratio.

## Usage
1. Open `certificate.html` in any modern web browser.
2. Fill in the participant's details (Name, Department, Batch, CPC-ID).
3. Click **Update Preview** to preview the generated certificate.
4. Click **Print / Save PDF** to save or print. 
   *(Tip: When saving as PDF in Chrome/Safari, ensure layout is set to 'Landscape', paper size to 'A4', and 'Background graphics' is enabled if needed, though the app uses print-color-adjust for native support).*

## Technologies Used
- HTML5
- CSS3 (Flexbox, CSS Grid, `@media print` directives)
- Vanilla JavaScript (Zero dependencies)
